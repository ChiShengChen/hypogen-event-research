# 金融假說風格 benchmark

純 Astra 使用簡短請求和共用結構化輸出。現行 Harness 經正常報告流程產生多空假說，轉成相同評分欄位，從原稿映射引文。這組保留原始報告，假說若無獨立財務重要性欄位即留空。
所有方法均停用搜尋。評分只看假說及其引用。

已完成 2/4 案雙順序評分。產生模型為 `gpt-6.2-astra`，評審為 `gpt-6.2-sol`。
每案的 2 種方法用同一份截止日證據及同一模型，各呼叫一次，評估兩條假說。
兩輪評審交換匿名候選的呈現順序。每項 0 至 2 分，表格使用兩輪平均。
完整合格的假說組在配對比較時優先。若合格狀態相同，配對比較使用兩輪平均分。
不在快照內的引用由程式判定。兩輪評審均指出同一候選引用的原文反證或事後事實時，該候選也判不合格。
分數衡量寫出可驗證研究假說的品質。日後是否實現須另以事前固定的結果定義評估。
