# 跨公告數值推理研究待辦

論文要回答哪一類跨期取值錯誤會被差額評分掩蓋，以及它會在什麼條件下發生。先完成同公告、同候選的機制對照，再判斷是否擴大發生率估計或保留逐欄發布的方法主張。

## 已有證據

- 歷史 Harness 在 3 家發行人、9 次可計算回傳中出現 6 次精確抵消。這些回傳包含同一發行人的重跑。 [歷史逐次誤差](artifacts/archive-error-magnitudes.csv)
- 新批 7 家發行人全部完成配對。Astra 和 Claude 的差額與完整取值均各 7/7，精確抵消均為 0/7，各自的 Wilson 95% 區間為 0–35.4%。兩批同時有發行人、輸入表示和處理方式的差異。 [新發行人審計](prevalence/report.md)
- 相同候選的逐欄核對在另一批保留集由 4/5 提到 5/5，兩組零誤發布。兩個模型都只在 Ziff Davis 多保留一個欄位，Astra 直接作答同為 5/5。 [完整公告政策比較](full-document/interpretation.md)

## 優先做同一批公告的機制對照

- [ ] **重現歷史錯誤。** 先找出產生歷史回傳的 Harness 程式版本與原始擷取紀錄，封存程式雜湊及所需的相容轉接。用 GitLab、Pure Storage 和 Sprinklr 驗證重播能重現每次的新舊金額及差額。若只能重建已存的輸出，標為歷史診斷。
- [ ] **封存新案例與對照。** 納入前後都可計算、具單季與累計並列、跨頁表頭或新舊指引共列的真實公告。記錄發行人去重及排除原因。歷史回歸排除在新案計分。新案推論前封存正解、等價列欄、預算、最低有效配對數、最小有意義效果及停止規則。
- [ ] **只改累計欄定位。** 同案比較直接作答、凍結的舊 Harness，以及同一候選只替換前後累計營收定位後的重算。其他欄位、口徑與 Decimal 算式固定。將使用人工正確定位的診斷組獨立記錄；若原擷取沒有足夠資料供舊版重播，保留缺件原因。需要模型呼叫的兩組使用相同證據、模型、推理強度、搜尋設定、呼叫和時間預算。
- [ ] **檢查機制與邊界。** 逐案列前次誤差、最新誤差及兩者相減後的差額誤差。只有新舊絕對值的非零誤差相同、且回傳差額自洽才計精確抵消。另列容差掩蓋、來源引用錯誤、缺欄和重算錯誤。以發行人為單位報配對差異，重跑用來衡量變異。若只更換累計欄即可消除同額誤差，就將歸因限於符合這個條件的案例；若回覆不齊或缺少可歸因案例，按預註冊停止。

## 依機制結果安排後續

- [ ] **量發生範圍。** 將一般來源樣本和刻意收集的困難案例分開。一般樣本估發生率與區間，困難樣本測失敗條件。依預期合格差額數估樣本量，安排雙人獨立標註與分歧裁決。若主張跨財務任務，另外在獨立的跨期差額任務複驗。
- [ ] **測逐欄方法的實際增益。** 以模型自行逐欄作答或暫緩作主要對照，兩組共用數字解析和重算。在獨立校準集選門檻，到保留集比較同風險下的有效覆蓋。另列實際發布發行人數、置信區間及跨案效果。以增益跨多家發行人重現作為保留方法主張的前提。
- [ ] **整理投稿產物。** 保存來源與版本雜湊、逐案輸入和 QA、帶符號誤差、等價引用裁決、執行帳本及失敗案例。主圖比較只看差額與核對完整取值的得分，另畫出舊版和單欄替換的配對誤差。將已觀察的機制、發生率、發布增益分成三項主張，各附適用範圍。
